# AquaFlow Demo

Prompt: Build a Modern Water Delivery & E-commerce Website (Demo)

Objective

Create a modern, responsive, and professional website for selling bottled water online. This is a frontend demo only with no authentication, no database, and no backend. All product data should be stored in local JSON or JavaScript objects. The website should simulate a real e-commerce experience with a clean and premium design.
